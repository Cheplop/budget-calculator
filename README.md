Name: Remiel Charles O. Fugnit  
Section: IT3R4

Description

This is a simple Python budget calculator. It asks the user for their budget and different expenses such as food, transportation, and school expenses. It calculates the total expenses and shows how much money is left from the budget.

How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the program using: python budget-calculator.py
